# Mosspeak

Браузерная 3D-песочница: ходишь, ломаешь и ставишь блоки, строишь, летаешь в творческом режиме и выживаешь с голодом. Мир остаётся в этом браузере, аккаунт и сервер не нужны.

Название, интерфейс и текстуры свои. Чужие ресурсы не используются.

Репозиторий: https://github.com/Larisa-coding/Minecraft  
Ветка `main` собирается на Vercel как Vite-приложение. После пуша подожди новую сборку и обнови страницу.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite.

```bash
npm test
npm run lint
npm run build
npm run preview
```

`npm run build` сначала проверяет TypeScript, потом кладёт статику в `dist`. Переменные окружения не нужны.

## Как играть

### Компьютер

| Действие | Клавиши |
| --- | --- |
| Ходьба | W A S D или стрелки, сразу, без клика |
| Прыжок | Пробел |
| Бег | Ctrl или двойное W, держится, пока идёшь вперёд |
| Присед | Shift |
| Обзор | Клик по миру, затем мышь |
| Сломать / поставить | ЛКМ / ПКМ по прицелу |
| Поставить в точку экрана | Короткий клик, когда камера отъехала |
| Приблизить / отдалить | Колесо, `+` / `−`. F5 возвращает вид от первого лица |
| Слот | 1–9 или панель внизу |
| Инвентарь | E |
| Ягоды | F в выживании |
| Полёт | F или двойной пробел в творческом режиме. Пробел вверх, Shift вниз |
| Инструменты мира | C |
| FPS | F3 |
| Пауза | Esc |

### Телефон

Играть можно вертикально и горизонтально. Горизонтально обзор шире.

- Слева джойстик. До упора вперёд — бег.
- Справа движение пальца крутит камеру. Короткое касание ставит блок в эту точку.
- Справа внизу: блок по прицелу, присед, красная кнопка ломает, треугольник прыгает.
- Двойное нажатие прыжка в творческом режиме включает полёт. Удержание поднимает, присед опускает.
- «Дальше» и «Ближе» меняют камеру. Горизонтально они слева сверху, вертикально справа под паузой. Щипок двумя пальцами делает то же.
- Сумка и пауза справа сверху.
- Ночью появляются зомби. Красная кнопка бьёт того, кто в прицеле. Клинки лежат в сумке, раздел «Оружие».
- Жест вниз крутит обзор. Страница сама не прокручивается, поэтому браузер не прячет адресную строку от этого жеста. Полностью убрать строку можно только если добавить сайт на экран «Домой».

## Сохранения

Всё локально.

- Настройки и id последнего мира — `localStorage`, ключ `mosspeak-settings-v1`.
- Миры — IndexedDB, база `mosspeak`, хранилище `worlds`.
- В файл попадают только правки поверх генератора, не вся карта. Одинаковые seed и версия генератора дают одну местность, постройки лежат отдельно.
- Формат сохранения `1`, у файла есть контрольная сумма.
- Экспорт и импорт — в «Мои миры».
- Обновление страницы возвращает в меню. Прогресс уже записан.

## Деплой

`vercel.json` задаёт Vite, `npm run build` и `dist`. Любой путь отдаёт `index.html`, потому что маршрутов на сервере нет.

## Структура

- `src/game` — мир, чанки, блоки, физика, камера, звук
- `src/screens` — меню, HUD, телефонные кнопки
- `src/storage` — IndexedDB, настройки, формат сейва
- `tests` — генерация, физика, инвентарь, сохранения

## Ограничения

Ступени — полные кубы, плиты без поворота. Вода не течёт, света по блокам нет, чанки считаются на главном потоке. Зомби живут только в текущей сессии и появляются ночью. Сглаживание включается при следующем входе в мир.
