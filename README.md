# Mosspeak

Браузерная 3D-песочница с кубическим миром. Можно ходить, ломать и ставить блоки, строить, переключать творческий режим и выживание, а миры сохраняются локально в браузере.

Название, интерфейс и текстуры собственные. Это не Minecraft и не использует его ресурсы.

## Стек

- React, TypeScript, Vite
- Three.js
- Zustand
- IndexedDB и localStorage
- Vitest, ESLint

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite.

## Проверки

```bash
npm test
npm run lint
npm run build
npm run preview
```

## Сохранения

Игра не требует аккаунта и сервера.

- Настройки и id последнего мира лежат в `localStorage`.
- Миры, правки блоков, инвентарь и позиция — в IndexedDB (`mosspeak`).
- В файл пишутся только отличия от генератора с этим seed, поэтому постройки не пропадают и мир не хранится целиком.
- Формат сохранения версии `1`, у файла есть контрольная сумма.
- Экспорт и импорт доступны в разделе «Мои миры».

Одинаковые seed и версия генератора дают одну и ту же базовую местность. Постройки хранятся отдельно и накладываются поверх.

## GitHub и Vercel

```bash
git init
git add .
git commit -m "Add Mosspeak voxel sandbox"
git branch -M main
git remote add origin https://github.com/Larisa-coding/Minecraft.git
git push -u origin main
```

В Vercel импортируйте этот репозиторий. Framework Preset: Vite. Команда сборки: `npm run build`. Каталог: `dist`. Переменные окружения не нужны.

`vercel.json` отдаёт `index.html` для клиентских путей. Обновление страницы открывает игру заново с главного меню, прогресс уже записан локально.

## Управление

- WASD, пробел, Shift, Ctrl
- Мышь после клика по миру, ЛКМ / ПКМ, колесо, 1–9
- E — инвентарь, C — творческие инструменты, F5 — камера, F — еда, Esc — пауза, F3 — FPS
- На телефоне: джойстик слева, обзор справа, отдельные кнопки строительства

## Структура

- `src/game` — движок, чанки, блоки, физика, звук
- `src/screens` — меню и интерфейс
- `src/storage` — сохранения и настройки
- `tests` — генерация, физика, инвентарь, формат мира
